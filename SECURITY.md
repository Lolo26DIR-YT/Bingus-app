# Politique de Sécurité (Security Policy)

**Lolo26DIR** prend la sécurité de ses projets, logiciels très au sérieux. Si vous découvrez une vulnérabilité ou un problème de sécurité, nous vous remercions de nous le signaler de manière responsable.

## Versions Prises en Charge

Nous appliquons activement des correctifs de sécurité sur les versions suivantes :

| Version | Prise en charge |
| ------- | ----------------------- |
| v1.3.x  | ✅ Oui                  |
| < v1.3  | ❌ Non (Mettez à jour)  |

## Signaler une Vulnérabilité

**Merci de NE PAS ouvrir d'Issue publique pour signaler une faille de sécurité.** Pour signaler un problème critique ou une vulnérabilité :
1. Envoyez un rapport détaillé par message privé sur le compte **Lolo26DIR** sur discord.
2. Incluez une description claire du problème, les étapes pour le reproduire (PoC) et l'impact potentiel sur l'application.

## Notre Processus

- **Accusé de réception :** Nous nous engageons à répondre et à accuser réception de votre rapport sous 48 heures.
- **Correction :** Une fois la faille validée, nous travaillerons sur un correctif qui sera publié d'abord sous forme de *Pre-release* pour validation, puis injecté dans la version stable officielle.
- **Remerciements :** Si vous le souhaitez, votre contribution et votre aide pour sécuriser le projet seront mentionnées dans le Patch Note de la prochaine Release !
